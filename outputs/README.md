# 📈 Experimental Outputs, Visualizations & Benchmark Reports

This directory archives all diagnostic figures, statistical charts, unsupervised cluster visualizations, multi-model evaluation benchmarks, and live event telemetry logs generated by the system.

---

## 📂 Subdirectory Organization

```
outputs/
├── alert_events.json                   # Real-time structured alert event log (JSON format)
├── alert_log.csv                       # Tabular audit log with timestamps, states, and audio frequencies
├── realtime_hud_preview.png            # Snapshot preview of the Driver HUD and Cockpit display
├── eda/                                # Unit 1: Exploratory Data Analysis & Statistical Figures
│   ├── class_distribution.json         # Raw count & balance metadata
│   ├── class_distribution.png          # Stratified class histogram & bar charts
│   ├── correlation_heatmap.png         # Pearson correlation matrix heatmap
│   ├── feature_boxplots.png            # IQR outlier distributions and spread per feature
│   ├── feature_histograms.png          # Kernel density estimation & feature distributions
│   ├── scatter_plots.png               # Bivariate feature interaction scatter plots
│   └── summary_statistics.csv          # Mean, std, median, skewness, kurtosis per feature
├── clustering/                         # Unit 3: Dimensionality Reduction & Cluster Visualizations
│   ├── gmm_aic_bic.png                 # AIC & BIC curve model selection across k=2..8
│   ├── gmm_clusters_ellipses.png       # GMM 2D clusters with Gaussian covariance error ellipses
│   ├── hierarchical_clusters_2d.png    # Agglomerative Ward clustering scatter in 2D
│   ├── hierarchical_dendrogram.png     # Full linkage distance hierarchical dendrogram
│   ├── kmeans_clusters_2d.png          # K-Means 4-cluster centroid partition in 2D space
│   ├── kmeans_elbow_silhouette.png     # Dual-axis Inertia (Elbow) & Silhouette score plot
│   ├── pca_2d_projection.png           # 2D projection onto first two Principal Components (PC1, PC2)
│   └── pca_scree_plot.png              # Scree plot showing individual & cumulative explained variance
└── evaluation/                         # Unit 2, 4 & 5: Model Evaluation & Benchmarks
    ├── adaboost_stagewise_error.png    # Boosting stagewise training & validation error decay
    ├── all_models_confusion_matrices.png# Grid of confusion matrices across all 8 architectures
    ├── bayesian_posterior_sample.png   # Bayesian posterior distribution and uncertainty spreads
    ├── benchmark_comparison.png        # Bar chart comparing Accuracy, F1, Latency & FPS
    ├── decision_tree_feature_importances.png # Gini importance ranking for decision tree splits
    ├── decision_tree_structure.png     # High-resolution visual representation of pruned tree rules
    ├── hmm_state_sequence_decoding.png # Viterbi vs. Naive state sequence temporal timeline
    ├── hmm_transition_matrix.png       # 4x4 Markov state transition probability heatmap
    ├── model_comparison_metrics.csv    # Benchmark CSV with accuracy, latency, FPS, memory size
    ├── model_comparison_summary.md     # Auto-generated markdown report summary
    ├── multi_model_roc_curves.png      # Multi-class One-vs-Rest ROC curves with micro/macro AUC
    ├── random_forest_feature_importance.png # Mean Decrease Impurity (MDI) feature importances
    ├── random_forest_oob_trees.png     # Out-of-Bag (OOB) error convergence vs. tree count
    ├── regression_residuals_ridge.png  # Fatigue score regression residuals and Q-Q normality plot
    └── svm_decision_boundary_rbf.png   # Non-linear RBF decision boundary contour projection
```

## 📝 Real-Time Alert Logs

Live alerts generated during system operations are written concurrently to:
- **`alert_log.csv`**: Timestamped CSV entries with `timestamp`, `frame_index`, `driver_state`, `ear`, `mar`, `perclos`, `alert_level`, and `audio_freq_hz`.
- **`alert_events.json`**: Structured JSON array suitable for telemetry dashboards and fleet analytics.
